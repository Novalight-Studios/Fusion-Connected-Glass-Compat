# 🔗 Fusion Connected Glass Compat

Fusion Connected Glass Compat (FCG Compat) adds compatibility between the Fusion Connected Glass and other mods.

## ✨ Compatibility

- [Dawn of Time](https://modrinth.com/project/RgWXq0La)
- [Deeper and Darker](https://modrinth.com/project/fnAffV0n)
- [Eternal Starlight](https://modrinth.com/project/XvcfUGfB)
- [Luminous: Overworld](https://modrinth.com/project/HT2F6lNL)
- [Naturalist](https://modrinth.com/project/F8BQNPWX)
- [ProtoManly's Weather](https://modrinth.com/project/TfCsmTLI)
- [Regions Unexplored](https://modrinth.com/project/Tkikq67H)
- [The Aether](https://modrinth.com/project/YhmgMVyu)
- [The Twilight Forest](https://www.curseforge.com/minecraft/mc-mods/the-twilight-forest)
- [The Undergarden](https://modrinth.com/project/Ejfl5qDL)
- [Unusual End](https://modrinth.com/project/WKsNOKFh)
- [Wilder Wild](https://modrinth.com/project/AtHRJSUW)

## 📦 Installation

You can download Fusion Connected Glass Compat on [Modrinth](https://modrinth.com/project/uMulT97B) or [CurseForge](https://www.curseforge.com/minecraft/texture-packs/fcg-compat)

## ⚙️ Requirements

You also need the following mod and resource pack for it to work properly:

- [Fusion](https://modrinth.com/project/p19vrgc2)
